# Manual overrides for isolated-word POS ambiguity. spaCy has no sentence
# context; these are hand-picked to match player intent.
#
# Format: surface<TAB>lemma. These win over BOTH the wordfreq-derived and
# grammar-generated forms.json entries (see pipeline/build_forms.py). Neither
# entry below shadows an existing standalone vocabulary lemma: "leaves" and
# "axes" are not themselves vocabulary.txt entries, only their overridden
# targets ("leaf", "axe") and the words they were wrongly resolving to
# ("leave", "axis") are.
#
# Advisor review (Phase 1.5.1 finalization) removed six other overrides that
# were in this file (saw->see, left->leave, rose->rise, bore->bear,
# wound->wind, lay->lie): each of those surface forms IS also a standalone
# vocabulary lemma with its own unrelated meaning (saw the tool, left the
# direction, rose the flower, wound the injury, bore ..., lay the verb "to
# lay"), so overriding them would have made that meaning permanently
# unreachable by typing the word directly. Decision: accept the isolated-word
# POS ambiguity for those six rather than shadow a standalone word. See the
# lemma-shadowing safety rule in CLAUDE.md.
leaves	leaf
axes	axe
